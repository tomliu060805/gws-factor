# The Cost of Silence — Conditional Under-disclosure and the Cross-Section of Chinese Stock Returns

Research code for a study of how ESG **disclosure behavior** is priced in China's
A-share market. The headline finding reverses the premise of the greenwashing
literature: what is systematically priced is not exaggeration, but **silence** —
firms that disclose relatively little, conditional on size, style, industry and
their *actual* ESG performance, earn lower subsequent returns.

The full write-up is in [`paper/main.pdf`](paper/main.pdf).
A Chinese-language project log with the complete result history is in
[`README_zh.md`](README_zh.md).

---

## Key results

| | Defensive spec | Baseline spec |
|---|---|---|
| Monthly IC (t) | 0.0122 (3.45) | 0.0136 (4.23) |
| Monthly RankIC (t) | 0.0103 (2.87) | 0.0124 (3.45) |
| Silent decile vs. peers, CH-3 alpha (t) | −4.16%/yr (−2.92) | −4.63%/yr (−4.00) |
| Exclusion portfolio, CH-3 alpha (t) | +0.46%/yr (2.91) | +0.52%/yr (4.00) |

*Sample: 119 monthly cross-sections (2015-01 to 2024-12), ~969 stocks/month.
CH-3 = Liu, Stambaugh & Yuan (2019) China three-factor model, built from the
same daily data. "Defensive spec" lags the signal until after annual reports
are published and removes any cross-year standardization constant.*

Three competing explanations are rejected and one channel survives:

- **Not greenwashing punishment** — a governance-dimension placebo is as strong
  as the environmental one; no amplification in polluting industries; penalty
  announcements produce *positive* CARs (+2.76%, t=4.98).
- **Not a liquidity premium** — silent firms are *more* liquid; mediation share
  is 7.0%; the signal survives Amihud neutralization.
- **Not size or quality** — stronger in large caps; correlation with a quality
  composite is 0.001, with a Fama-MacBeth marginal t of 3.68 on top of it.
- **Price discovery survives** — the discount concentrates where
  Hou-Moskowitz (2005) price delay is high, and this holds inside the
  low-idiosyncratic-volatility subsample.

Orthogonalization is a *necessary* condition: the raw disclosure gap has no
predictive power at all (IC = −0.0004, t = −0.10).

## Repository layout

```
src/greenwash/          # library
  config.py             #   all paths (relative + env-var overrides)
  gws.py                #   disclosure-gap construction
  pipeline.py           #   monthly signal panel + cross-sectional neutralization
  marketdata.py         #   daily prices -> monthly panel, styles, Amihud, price delay
  chfactors.py          #   CH-3 / FF3 factor construction, alpha tables
  fe.py                 #   fixed-effects OLS with clustered SE (reghdfe equivalent)
  factor.py             #   IC / RankIC / decile utilities
analysis/               # numbered, runnable analyses (01-20)
crawler/                # akshare + CNINFO collectors for external evidence
paper/                  # LaTeX working paper (main.tex, references.bib, figs/)
figures/                # generated figures, versioned by purpose
output/                 # result tables (git-ignored; regenerated by scripts)
run_all.py              # run analyses 01-06 end to end
```

## Data requirements

**No licensed data is distributed with this repository.** Three external
sources are needed; all are configured through environment variables (see
`src/greenwash/config.py`):

| Variable | Contents | Default |
|---|---|---|
| `GWS_DATA_DIR` | annual ESG/financial panel (`.dta`) and the risk-free rate table | `../大创` |
| `GWS_MARKET_DIR` | daily A-share prices, valuations and index prices (parquet, one file per date) | `<repo>/data/market` |
| `GWS_INDEX_WEIGHTS` | CSI 300 / CSI 500 constituent weights | `<repo>/data/index_weights` |

Data collected by `crawler/` (ESG rating snapshots, penalty filings) is written
to `data_ext/` and is also git-ignored; rerun the crawlers to regenerate it.

## Quickstart

```bash
pip install -r requirements.txt          # + pyarrow for analyses 07 and above
export GWS_DATA_DIR=/path/to/esg_panel
export GWS_MARKET_DIR=/path/to/market_data

python run_all.py                        # panel analyses 01-06
python analysis/07_monthly_barra_ic.py   # monthly IC with style neutralization
python analysis/14_defensive_baseline.py # defensive specification (paper's primary)
python analysis/16_information_barrier.py# mechanism tests (liquidity vs. price discovery)
python analysis/17_risk_adjusted_alpha.py# CAPM / FF3 / CH-3 alphas
```

The first run of any script from `07` onward builds a monthly market panel and
caches it to `output/monthly_panel.parquet` (a few minutes); later runs load
the cache.

To rebuild the paper:

```bash
cd paper && pdflatex main && bibtex main && pdflatex main && pdflatex main
```

## Scope and limitations

- This is a study of **cross-sectional predictability, not causality**.
  Disclosure is a firm's choice; the neutralization controls observables only.
  An attempted difference-in-differences design around the April 2024 disclosure
  mandate is reported as a **failed identification attempt**
  (`analysis/18_mandate_did.py`) rather than dropped: a major market-structure
  policy was announced the same day and cannot be separated from the mandate.
- Magnitudes are modest (monthly IC ≈ 0.012, portfolio gain ≈ 0.5%/yr). The
  signal suits a low-correlation component or exclusion list, not a standalone
  strategy.
- Coverage is limited to ~970 rated firms per month (about a fifth of the
  market, large-cap tilted), and the effect **disappears under value weighting**.
- Rating-disagreement tests use current snapshots rather than point-in-time
  data; monthly archiving has been set up so the test can be redone properly.
